# windows-ad-lab
Windows Active Directory Lab

A virtualized Windows environment built to develop practical experience with Windows Server, Active Directory Domain Services, DNS, Windows clients, and infrastructure troubleshooting.

## Environment

- Hypervisor: VirtualBox
- Domain Controller: Windows Server
- Clients: Windows
- Directory Services: Active Directory Domain Services
- DNS: Windows DNS
- Network: Virtualized lab network

## Objectives

- Deploy a Windows Server Domain Controller
- Configure Active Directory Domain Services
- Configure DNS
- Create and manage domain resources
- Join Windows clients to the domain
- Test client/server connectivity
- Troubleshoot DNS and network configuration issues

## Troubleshooting

This lab includes documentation of problems encountered during deployment and the diagnostic process used to identify and resolve them.

## Skills Demonstrated

- Windows Server
- Active Directory
- DNS
- VirtualBox
- Windows client administration
- Network troubleshooting
- Systematic troubleshooting
- Technical documentation
